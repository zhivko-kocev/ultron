# Keys

Press **Super+K** for every key, searchable. `ultron keys` reads them from the sway config (`home/sway/.config/sway/config` in the ultron folder) and your own files in `~/.config/ultron/sway/` (marked "yours"; a key you bind again there replaces ultron's), so the list is always what sway really uses. To add or change keys: [customize.md](customize.md#keys-monitors-and-window-rules-sway).

## Agentic keys

| Key | What it does |
|---|---|
| Super+B | Boss: go to the boss agent on workspace 1 |
| Super+BackSpace | Back to the workspace you were on before (same as Super+Ctrl+Tab) |
| Super+A | Attention: the oldest agent that needs you (press again for the next), else the newest window agents showed you on a workspace you haven't visited since (press again for the next such workspace) |
| Super+N | New thread (when the boss is Jocasta) |
| Super+Shift+S | Region screenshot for the boss: saves it, copies its path, goes to the boss |
| Super+M | Focus mode on / off: nothing moves you, notifications are held, a workspace turns red when an agent needs you |
| Super+Shift+J | Note a Jocasta friction point (when the boss is Jocasta) |
